# HERMES · 迁移控制面 — 逐屏还原提示词（v0 / Cursor / Claude 复刻用）

> 用法：先把「0. 全局系统提示」作为 system / 项目规则；再按屏发送「1–8」中的单屏提示词。
> 每屏都给出**布局、内容、组件状态、交互、验收**，可直接产出接近 `index.html` 的结果。
> **落地形态提醒**：本设计稿的独立壳仅用于评审。生产落地为 Hermes **React Plugin SDK + Dashboard `/flow` tab**（`dashboard/manifest.json` + 预构建 `dist/index.js` + `plugin_api.py` 的 FastAPI router + 宿主 WebSocket），复用宿主侧栏/顶栏，不自建全局壳、不自带 React。复刻时请把 8 屏当作 tab 内的 8 个子页。
>
> 目标技术栈默认 **HTML + 原生 CSS + 原生 JS**（与设计稿一致，单文件可运行）；生产落地时映射为 React 组件（Hermes Plugin SDK），样式 token 原样复用。

## 9. 复刻工作流建议

1. **先复刻设计系统**：把第 0 节的 tokens（颜色/字号/间距/圆角/状态色）落成 `:root` 变量，再拼组件（按钮/输入/状态徽标/面板/表格/KPI/进度/开关/Tab/抽屉/命令面板/Toast）。
2. **逐屏生成**：每屏单独一个 prompt（第 1–8 节），输出整页 HTML；最后合并为单文件或 Vue 页面。
3. **数据先固化**：直接复用本文中的文件、评分、异常、时间戳，保证 8 屏自洽；不要随机造数。
4. **状态要全**：正常/运行/警告/失败/空闲/空态/加载/骨架/错误各至少一处；hover/focus/active 不可省。
5. **验收**：用 1600×1000 截图对比 `screenshots/`；检查雷达图、DAG 连线、迷你趋势图是否真实渲染。
6. **不要**引入外网字体、图标库 CDN、紫色渐变或玻璃拟态；图标一律内联 SVG。
